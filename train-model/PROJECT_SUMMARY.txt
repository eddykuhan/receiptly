│  🎯 HOW IT WORKS                                                        │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  Input:  "MYDIN WHOLESALE HYPERMARKET BUKIT MERTAJAM"                   │
│           ↓                                                             │
│  [TF-IDF Vectorization]  (Converts text to numerical features)         │
│           ↓                                                             │
│  [Random Forest Classifier]  (Trained ML model)                        │
│           ↓                                                             │
│  Output: {                                                              │
│            merchant: "MYDIN",                                           │
│            location: "BUKIT_MERTAJAM",                                  │
│            merchant_confidence: 0.95,                                   │
│            location_confidence: 0.92                                    │
│          }                                                              │
│                                                                         │

│  🎓 MODEL DETAILS                                                       │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  Algorithm:     Random Forest Classifier (100 trees)                    │
│  Vectorization: TF-IDF with 1-3 n-grams                                 │
│  Features:      Up to 1000 TF-IDF features                              │
│  Output:        Merchant name + Location (multi-output)                 │
│  Confidence:    Probability scores from Random Forest                   │
│                                                                         │
│  Why this approach?                                                     │
│  • Works well with limited data                                         │
│  • Fast training and prediction                                         │
│  • Provides confidence scores                                           │
│  • Easy to understand and debug                                         │
