📋 PROJECT OVERVIEW
═══════════════════════════════════════════════════════════════════════════════

This Python project uses OpenAI's GPT-4 Vision API to automatically extract
merchant name and address information from receipt images.

🎯 WHAT IT DOES:
   • Uploads receipt images to GPT-4 Vision
   • Extracts merchant name from receipt header
   • Extracts merchant address from receipt header
   • Returns structured JSON output
   • Supports batch processing of multiple receipts

📊 OUTPUT FORMAT
═══════════════════════════════════════════════════════════════════════════════

The extractor returns JSON with the following structure:

{
  "merchant_name": "ABC Supermarket",
  "merchant_address": "123 Main Street, City, State 12345",
  "raw_response": "..."
}

Fields:
   merchant_name      The business/store name from receipt header
   merchant_address   Complete address (multi-line addresses combined)
   raw_response       Full GPT-4 Vision API response

🎓 HOW IT WORKS
═══════════════════════════════════════════════════════════════════════════════

1. Image Encoding
   Receipt image is read and encoded to base64 format

2. API Request
   Encoded image + specialized prompt sent to GPT-4 Vision API

3. AI Analysis
   GPT-4 Vision analyzes the receipt image and identifies:
   - Merchant name (from header)
   - Merchant address (from header)

4. Response Parsing
   JSON response is parsed and validated

5. Output
   Results displayed and optionally saved to file

🔍 EXTRACTION GUIDELINES
═══════════════════════════════════════════════════════════════════════════════

The prompt instructs GPT-4 Vision to:
   ✓ Extract ONLY from the TOP portion of the receipt
   ✓ Focus on merchant name and address
   ✗ Exclude invoice numbers, dates, cashier IDs
   ✗ Exclude phone numbers
   • Combine multi-line addresses into single string
   • Return "Not found" if information is missing

📝 BEST PRACTICES
═══════════════════════════════════════════════════════════════════════════════

Image Quality:
   • Use clear, well-lit photos
   • Ensure text is readable
   • Avoid heavy shadows or glare
   • Higher resolution generally works better

Receipt Position:
   • Ensure merchant info at top is visible
   • Avoid cutting off the header
   • Straight-on photos work best

Testing:
   • Start with 1-2 test images
   • Verify output quality
   • Adjust image quality if needed

Cost Management:
   • Monitor API usage regularly
   • Set spending limits
   • Use batch processing efficiently

🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Problem: "OpenAI API key not found"
Solution: Create .env file and add your API key
   $ cp .env.example .env
   $ nano .env

Problem: "Image file not found"
Solution: Check file path and ensure image exists
   $ ls receipts/

Problem: "Module not found"
Solution: Install dependencies
   $ source venv/bin/activate
   $ pip install -r requirements.txt

Problem: Permission denied on quickstart.sh
Solution: Make script executable
   $ chmod +x quickstart.sh

Problem: Poor extraction quality
Solution: 
   • Use higher quality images
   • Ensure receipt header is visible
   • Try different lighting/angle

🎯 INTEGRATION WITH RECEIPTLY
═══════════════════════════════════════════════════════════════════════════════

This module can be integrated into the main Receiptly project:

1. As a Fallback Service
   Use when Azure OCR fails to extract merchant information

2. For Validation
   Compare GPT-4 Vision results with existing OCR methods

3. Enhanced Accuracy
   Use for critical merchant data extraction

4. Hybrid Approach
   Combine multiple extraction methods for best results

Example Integration:
   ```python
   from gpt4_vision_extractor.receipt_extractor import ReceiptExtractor
   
   def extract_merchant_info(image_path):
       # Try Azure first
       azure_result = azure_ocr(image_path)
       
       # Fallback to GPT-4 Vision if needed
       if not azure_result.get('merchant_name'):
           extractor = ReceiptExtractor()
           return extractor.extract_merchant_info(image_path)
       
       return azure_result
   ```
